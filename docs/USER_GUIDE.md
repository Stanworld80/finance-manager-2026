# Finance Manager 2026 - User Guide

This document is intended to help end-users navigate the application. 

## Key Concepts

- **Real Accounts**: Typical bank accounts (e.g., Checking, Savings) reflecting your actual money.
- **Virtual Accounts (Envelopes)**: Budgets or specific goals mapped onto your Real Accounts to help you organize your finances.

## Dashboard
The dashboard provides an overview of:
- Total balance across all accounts.
- Upcoming recurring transactions.
- Recent activity (Flux récents).

## Transactions
- **Incomes (Revenu)**: Adds money to a specific real and virtual account.
- **Expenses (Dépense)**: Deducts money from a real and virtual account.
- **Transfers (Virement)**: Moves money between two virtual accounts.
