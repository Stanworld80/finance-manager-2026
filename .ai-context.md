# Project Rules & Philosophy
- **Framework:** Flutter (Latest Stable).
- **Target:** Android & Web (Responsive mandatory).
- **State Management:** Riverpod (avec Code Generation) OU BLoC (selon votre choix).
- **Architecture:** Clean Architecture (Domain / Data / Presentation).
- **Styling:** Pas de hardcoded colors/sizes. Utiliser `Theme.of(context)`.
- **Quality:**
  - Null Safety strict.
  - Pas de `print()`, utiliser `logger`.
  - Chaque Widget complexe doit être découpé.
- **Testing:**
  - Pour chaque feature : 1 Test Unitaire + 1 Test Widget basique.
  - Utiliser `mocktail` pour les mocks.
